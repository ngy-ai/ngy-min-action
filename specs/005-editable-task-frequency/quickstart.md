# Quickstart: 任务频率可修改验收

**Feature**: `005-editable-task-frequency`

## 自动化门禁

```bash
cargo fmt --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all-targets --all-features
```

## 场景 1：把「每天」改成「每 3 天」（FR-001 / FR-004）

1. 创建任务「连读」，默认每天
2. 点该任务的「频率」

**预期**: 弹窗预选「每天」，参数输入框不显示。

3. 切到「每 N 天」，输入 3，保存

**预期**: 任务行显示「每 3 天」，名称、暂停/恢复按钮状态与复习进度都不变。

## 场景 2：非法参数（FR-003）

1. 打开频率弹窗，切到「每 N 天」
2. 分别输入 `0`、`abc`、`366` 后保存

**预期**: 每次都被拒绝，错误条说明取值范围，弹窗与输入内容保留，任务行频率不变。

3. 输入 `365` 保存

**预期**: 成功。

## 场景 3：改成当前值（边界）

1. 对一个「每天」任务打开弹窗，直接保存

**预期**: 成功，不报错。

## 场景 4：暂停中的任务（FR-008）

1. 把任务暂停
2. 改频率为「每周 3 次」并保存

**预期**: 保存成功，任务仍是暂停，今日清单不因此生成行动。

## 场景 5：不追溯已生成的行动（FR-005 / FR-006）

1. 对一个今天已有行动的任务，把频率从「每天」改成「每周 1 次」

**预期**: 今天的行动仍在，状态不变；次日不再生成，直到间隔满足。

2. 再改回「每天」并跨日刷新

**预期**: 次日生成该任务的新行动。

## 通过标准

- 三条门禁全绿
- 场景 1–5 逐项符合预期
- `tasks.md` 全部勾选
