# Contract: 界面行为

**Feature**: `001-min-action-core` | **Type**: 桌面应用界面契约

界面契约是这类项目的对外接触面（宪法 IV）。本文件规定窗口、区域、状态与交互结果，不规定视觉风格。

## 1. 窗口构成

| 窗口 | 触发 | 关闭行为 |
| --- | --- | --- |
| 主窗口 | 程序启动 | 关闭即退出程序（不驻留后台） |
| 提示窗口 | 每个本地日首次满足 `should_notify` | 关闭即视为当天已提示 |

**主窗口最小化**: 最小化为常规最小化，后台的跨日检测与提示不受影响（FR-024）。

**单实例**: 启动时若已有实例在运行，主窗口聚焦到既有实例并退出本次启动，不出现两个进程同时弹窗。

## 2. 主窗口区域

```text
┌─────────────────────────────────────────────┐
│ 今日 [2026-11-02]          共 3 条 · 已顺延 2 条 │  ← 状态条
├──────────────┬──────────────────────────────┤
│ 目标 / 分类树 │ 行动列表（今日）或任务列表      │
│  ▼ 学习英语   │  ☐ 口语 · 复习 L1（第 1 级）    │
│    · 语法     │  ☐ 单词 · 背 10 个单词          │
│    · 口语     │  ☑ 阅读 · 精读一段              │
└──────────────┴──────────────────────────────┘
```

**状态条**: 必须同时给出当天行动总数与顺延数量（FR-013）；顺延数 > 0 时不可隐藏。

**行动行**: 展示「分类名 · 行动文案」，复习行动额外标注当前级别（FR-010）；行内提供「完成」「跳过」两个操作与撤销入口（FR-017）。

**空状态**: 当天无行动时展示引导文案（如何新建目标与任务），不显示空白列表（FR-035）。

## 3. 提示窗口

| 项 | 契约 | 依据 |
| --- | --- | --- |
| 层级 | 始终置顶，覆盖普通窗口 | FR-025 |
| 焦点 | 弹出时不夺取键盘焦点 | FR-025 |
| 内容 | 「今天有 N 条最小行动待完成」 | FR-025 |
| 操作 | 「查看今日清单」按钮 → 聚焦主窗口并切到今日视图 | FR-030 |
| 重复 | 同一天只允许出现一个提示窗口实例 | FR-026 |
| 静默 | 当天无待办时不弹出 | FR-028 |

**出现时机**: 本地日期变化后的 5 秒内（SC-010）；程序启动时若当天尚未提示，也按同一规则判定。

## 4. 错误呈现

- 表单校验失败：错误文案紧贴对应输入项，包含出错字段、期望规则与修正方式（FR-004 / FR-034）。
- 数据库失败：以顶部横幅呈现，不吞掉错误，不进入不可恢复的白屏。
- 禁止把不可信名称直接拼进布局而不做清理：换行与控制字符在入库前被拒绝，展示层仍做一次截断，防止超长名称撑破行高（FR-033）。

## 5. 数据与配置位置

- 数据库与日志位于同一应用数据目录下，由程序在首次启动时创建。
- 界面不提供「导出/导入」，不提供统计图表（超出本 feature 范围）。
