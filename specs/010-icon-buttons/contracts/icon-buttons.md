## 行为契约

| 编号 | 契约 |
| --- | --- |
| C-01 | 每个图标按钮的点击结果与替换前一致；危险操作仍进入二次确认，草稿不丢失 |
| C-02 | 每个图标按钮都有非空的悬停提示，文案与表中一致 |
| C-03 | 普通／主要／危险三档可区分：线宽与语义色不同；危险色来自 `error_fg_color` |
| C-04 | 命中区域固定 34×26，不小于被替换的 `small_button` |
| C-05 | 浅色与深色两套主题下形状完整、无缺字、无溢出；切换主题后同步换色 |
| C-06 | 主题三态下拉、表单标签、统计数值、空状态与错误提示保持文字 |
| C-07 | `Cargo.toml` 无新增依赖；`Color32::` 仍只在 009 的令牌文件 |
