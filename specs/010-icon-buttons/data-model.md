# Data Model: 用图标替换操作按钮

**Feature**: `010-icon-buttons` | **Date**: 2026-11-05

本 feature 不改动持久化数据；「模型」指界面层的图标实体与按钮映射。

## 实体

### Icon（图标种类）

定义于 `src/app/icons.rs`，纯界面枚举，不进入领域层、不持久化。

| 取值 | 形状 | 典型用途 |
| --- | --- | --- |
| `Plus` | 十字 | 添加目标／分类／任务、创建、全部展开 |
| `Minus` | 横线 | 全部折叠 |
| `ChevronRight` / `ChevronDown` | 右／下折角 | 结构树展开与折叠 |
| `Pencil` | 斜笔 + 笔尖 | 改名 |
| `Cross` | 交叉线 | 删除、取消、关闭 |
| `Check` | 对勾折线 | 保存、完成、创建、知道了 |
| `Skip` | 右三角 + 竖线 | 跳过行动 |
| `CircularArrow` | 回转箭头 | 撤销、重置复习 |
| `Pause` / `Play` | 双竖线／右三角 | 暂停与恢复任务 |
| `Chart` | 三根柱 + 基线 | 统计面板 |
| `List` | 三条横线 | 查看今日清单 |

### IconButton（图标按钮）

| 字段 | 含义 | 约束 |
| --- | --- | --- |
| `icon: Icon` | 形状 | 必须来自上表 |
| `tip: &'static str` | 悬停文案 | 与替换前的中文标签一致，非空 |
| `semantic: Semantic` | 普通／主要／危险 | 决定线宽与颜色来源 |

- **尺寸**：固定 34×26 逻辑像素，命中区域不小于被替换的文字按钮
- **颜色**：普通与主要用 `text_color()`，危险用 `error_fg_color()`；不存颜色值
- **交互**：`Sense::click()`，`Response::on_hover_text(tip)`；不改变原有点击后的业务路径

## 映射表

完整逐按钮映射见 [contracts/icon-buttons.md](./contracts/icon-buttons.md)，那里是唯一权威。

## 不变量

- 每个 `ui.button` / `ui.small_button`（替换范围内）都有且只有一个 `IconButton` 对应项，提示文案不丢
- 危险操作（删除目标／分类／任务、删除确认、重置复习）语义为危险，且二次确认流程不变
- 主题三态下拉、`selectable_label` 选项、表单标签、统计数值、空状态与错误提示仍为文字
- `settings.theme`、业务表、行动状态、复习进度、每日上限、统计结果均不读写、不变化

## 校验规则

- 图标形状由枚举保证，无字符串解析，无外部输入
- 悬停文案为编译期静态字符串；集中映射表可逐个核对
- 无网络、无字体、无图片加载路径
