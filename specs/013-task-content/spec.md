# 013 任务内容与来源查看

## 概述

任务（Task）当前只有 `name`（标题），没有「内容」字段；今日最小行动（Action）虽已带 `task_id`
能回溯来源任务，但界面无法查看来源任务的说明。本特性给任务补上「内容」（富纯文本 + 图片/音频/
视频附件），并在行动备注弹窗里用左右两栏展示「来源任务 / 当前备注」，让使用者从待办即可看清
这条最小行动来自哪个任务、任务本身写了什么。

## 用户故事

### US1：任务有标题和内容

- 建立或编辑任务时，除名称外可填写「内容」：多行纯文本（上限 4000 字），文本里出现的
  `http(s)://` 链接在展示时可点击打开；可附加图片、音频、视频文件。
- 内容可为空（只填标题也合法）。
- 链接、图片、音频、视频在来源任务展示区统一呈现：图片内联，音频/视频提供「打开」按钮，
  点击后由操作系统默认程序处理（不在应用内解码播放）。
- 附件受目录约束：文件名不得含路径分隔符，文件需经过校验后复制到数据目录。

### US2：从待办查看来源任务

- 打开一条今日/历史待办的备注弹窗时，界面分为左右两栏：
  - 左栏：来源任务的标题与内容（渲染后的文本 + 媒体）。
  - 右栏：该行动自身的备注（沿用既有备注编辑/只读能力）。
- 只读态下两栏均为只读；可编辑态下仅右栏可改。

## 成功标准

- SC-1：新建任务可同时写入内容（文本 + 媒体附件），旧库经增量迁移保留全部业务数据。
- SC-2：按任务 `id` 可取回任务与它的媒体附件列表。
- SC-3：行动备注弹窗展示来源任务标题与内容；文本中的链接可点击，图片内联，音视频可打开。
- SC-4：非法媒体（超大小、扩展名不在白名单、图片解码失败）被拒绝并给出可执行错误。
- SC-5：内容文本上限 4000 字，超出或含非法控制字符被拒绝。

## 范围外

- 不在应用内解码/播放音频与视频（交给系统默认程序）。
- 不做富文本排版（粗体/颜色等），内容是纯文本 + 自动链接 + 媒体附件。
- 不做任务内容的全文搜索。
