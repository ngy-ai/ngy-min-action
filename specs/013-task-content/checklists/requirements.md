# 013 需求核对清单

- [ ] 任务可填写标题（既有 `name`）+ 内容（文本 + 媒体）
- [ ] 内容文本上限 4000 字，空白即空，非法控制字符被拒
- [ ] 内容可含 `http(s)://` 链接，展示时可点击打开浏览器
- [ ] 任务可附加图片、音频、视频；图片解码校验，音视频扩展名 + 大小白名单
- [ ] 媒体文件名单段校验，复制到 `<数据目录>/task_content/<任务 ID>/`
- [ ] 按任务 `id` 可取回任务与媒体列表
- [ ] 旧库增量迁移到 schema 4，业务数据保留
- [ ] 行动备注弹窗左右两栏：左来源任务，右当前备注
- [ ] 只读态两栏均只读
- [ ] 音频/视频由系统默认程序打开，不在应用内解码
