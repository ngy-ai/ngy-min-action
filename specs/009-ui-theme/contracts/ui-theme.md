# UI Contract: 主题切换与视觉令牌

**Feature**: `009-ui-theme` | **Date**: 2026-11-05

## 入口

顶栏右侧新增主题选择入口，与「统计」同一区域，显示当前选择（跟随系统 / 浅色 / 深色）。三种选择互斥，单处改动，不另设设置页。

## 行为契约

| 编号 | 触发 | 结果 |
| --- | --- | --- |
| C-01 | 用户选择浅色或深色 | 当前帧内应用到主界面、结构树、今日清单与所有已打开弹窗；弹窗内容与草稿保持不变 |
| C-02 | 用户选择跟随系统 | 界面立即按当前系统明暗显示；系统主题随后变化时自动跟随，不写库 |
| C-03 | 任意选择 | 写入本地设置；重启后首帧即为该选择，无可见闪烁 |
| C-04 | 首次启动 / 偏好记录缺失 | 按系统当前明暗显示，等价于「跟随系统」 |
| C-05 | 偏好记录不可识别 | 回退「跟随系统」，界面正常启动，错误不暴露给用户 |
| C-06 | 切换主题 | 行动、任务、复习进度、每日上限、统计结果均不变；不产生业务日志噪音 |
| C-07 | 任一主题 | 正文与背景对比度 ≥ 4.5:1，大字号 ≥ 3:1 |

## 视觉令牌契约

- 颜色、间距、字号集中在一处定义，界面其余代码 MUST NOT 出现颜色字面量
- 语义色（警告、危险、强调、弱文本）由两套主题各自定义；界面只读取语义色，不自行挑色
- 主要 / 次要 / 危险操作 MUST 可区分；危险操作（删除、`×`）保持既有二次确认
- 空状态统一用弱化文字；错误提示统一用危险语义色；「已顺延」用警告语义色
- 结构树、任务行、今日清单、统计面板的列对齐与长名称截断规则在两种主题下一致

## 可验证性

| 契约 | 验证方式 |
| --- | --- |
| C-01 / C-02 | headless 渲染：切换后 `ctx.theme()` 与偏好字段一致，弹窗渲染不 panic |
| C-03 / C-04 / C-05 | `tests/theme_test.rs` 覆盖默认值、往返、非法值回退；GUI 重启截图确认首帧 |
| C-06 | headless 用例对比切换前后的 `actions` / `tasks` / `stats` 快照 |
| C-07 | 令牌对比度单元测试 + GUI 截图人工确认 |
| 视觉令牌 | `git grep -nE 'Color32::' -- 'src/app'` 除令牌文件外无命中 |
