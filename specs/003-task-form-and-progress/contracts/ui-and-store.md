# Phase 1 Contract: 频率文案、批量进度读取与表单行为

**Feature**: `003-task-form-and-progress` | **Date**: 2026-11-03

## 领域层

```rust
impl Frequency {
    /// 人类可读的频率描述。
    ///
    /// 只用于展示，不参与调度判定。
    pub fn label(self) -> String;
}
```

| 输入 | 输出 |
| --- | --- |
| `Daily` | `每天` |
| `EveryNDays(3)` | `每 3 天` |
| `WeeklyN(2)` | `每周 2 次` |

**契约**: 纯函数，同一输入恒返回同一输出；不产生副作用。

## Store

```rust
/// 某分类下全部未删除任务的复习进度。
///
/// 无复习记录的任务不出现在结果中，调用方据此显示「未开始」。
///
/// # Errors
///
/// 读写失败时返回 `DomainError::Store`。
pub fn progress_for_category(&self, category: CategoryId) -> Result<Vec<ReviewProgress>, DomainError>;
```

**契约**:

- 只含未删除任务的进度，已删除任务的进度不可见
- 分类不存在或为空时返回空向量，不视为错误
- 顺序按 `task_id` 升序，同一输入稳定

## 表单行为

**新建任务表单**:

| 控件 | 行为 |
| --- | --- |
| 频率模式 | 三选一：每天 / 每 N 天 / 每周 N 次，默认每天 |
| 参数输入 | 仅在后两种模式下出现；切换模式时重置为该模式的默认值（3 天 / 2 次） |
| 提交 | 参数先经 `Frequency::from_parts` 校验，非法时展示错误并保留表单内容 |

**错误展示**:

- 每 N 天越界或非数字：`频率间隔 不合法：1 到 365 之间的整数`
- 每周 N 次越界或非数字：`每周次数 不合法：1 到 7 之间的整数`
- 失败时不创建任务，表单内容保留，与重名分类的失败行为一致

## 任务行展示

| 状态 | 频率 | 进度 |
| --- | --- | --- |
| 未复习过 | `每天` / `每 3 天` / `每周 2 次` | `未开始` |
| 复习中 | 同上 | `第 N 级，下次复习 YYYY-MM-DD` |
| 已巩固 | 同上 | `已巩固` |
| 暂停中 | 同上，可附加 `已暂停` | 同上述三种状态，暂停不影响展示 |

**重置复习**: 点击后刷新任务列表，进度立即回到「未开始」。
