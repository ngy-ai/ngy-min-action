# Quickstart: 任务频率选择与复习进度展示验收

**Feature**: `003-task-form-and-progress`

## 自动化门禁

```bash
cargo fmt --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all-targets --all-features
```

## 场景 1：三种频率都能创建（FR-001 / FR-004）

1. 新建目标「学习英语」，新建分类「口语」
2. 不修改频率，创建任务「每天任务」

**预期**: 任务行显示「每天」。

3. 频率选「每 N 天」，参数填 3，创建任务「隔三天任务」

**预期**: 任务行显示「每 3 天」。

4. 频率选「每周 N 次」，参数填 2，创建任务「每周两次任务」

**预期**: 任务行显示「每周 2 次」。

## 场景 2：参数校验（FR-002 / FR-003）

1. 频率选「每 N 天」，参数填 0，提交

**预期**: 拒绝，提示「1 到 365 之间的整数」，任务未创建，表单内容保留。

2. 参数改 366，提交

**预期**: 同样拒绝。

3. 频率选「每周 N 次」，参数填 8，提交

**预期**: 拒绝，提示「1 到 7 之间的整数」。

4. 参数清空，提交

**预期**: 拒绝，不产生任务。

## 场景 3：复习进度展示（FR-006 / FR-007 / FR-008）

1. 新建任务「连读」，查看任务行

**预期**: 显示「未开始」。

2. 在今日清单完成该任务，回到任务列表

**预期**: 显示「第 1 级，下次复习 YYYY-MM-DD」（次日）。

3. 点击「重置复习」

**预期**: 立即回到「未开始」。

> 已巩固状态（6 级）需要连续 6 次复习，跨日推进由 `tests/review_test.rs` 覆盖，手工只验收未开始与第 1 级两种展示。

## 场景 4：暂停任务的展示（边界）

1. 把已有复习进度的任务暂停

**预期**: 频率与进度展示不变，任务行出现「已暂停」标记。

## 通过标准

- 三条自动化门禁全绿
- 场景 1、2、3 逐项符合预期
- `tasks.md` 的对应任务全部勾选
- **已知偏差（记录用）**：暂停任务后，今日清单中该行动的名称退化为「·任务#1」。2026-11-03 手工验收发现，与本 feature 的改动无关，需单独立项
